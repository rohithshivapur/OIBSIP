# Basic Network Scanning with Nmap

## Task Objective

The objective of this task is to perform a basic network scan using Nmap to identify open ports, running services, service versions, and operating system information on an authorized target.

## Tool Used

- Nmap 7.991
- Windows PowerShell

## What is Nmap?

Nmap (Network Mapper) is an open-source network scanning tool used to discover hosts and services on a computer network. It can identify open ports, running services, service versions, and operating system information.

## Why Network Scanning Matters

Network scanning helps security analysts:

- Identify open ports and exposed services.
- Discover unnecessary network services.
- Identify potential security risks.
- Understand the attack surface of a system.
- Support vulnerability assessment and network security monitoring.
